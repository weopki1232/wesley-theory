# 🪑 โจ๊ะตอง — เว็บจองโต๊ะในห้องเรียน

> **โจ๊ะตอง** คือคำผวนของ **“จองโต๊ะ”**
> เว็บสำหรับให้นักเรียนจองที่นั่งในห้องเรียนล่วงหน้า โดยครูเป็นคนจัดผังโต๊ะของแต่ละห้องเอง

เว็บนี้เป็น **static site ล้วน** — มีแค่ไฟล์ HTML / CSS / JS ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีฐานข้อมูล
เปิดจากไฟล์ในเครื่องก็ได้ หรือเอาขึ้น GitHub Pages ฟรีก็ได้

---

## ✨ ทำอะไรได้บ้าง

### หน้านักเรียน (`index.html`)
- เลือกห้องเรียน และเลือก **วันที่** ที่อยากนั่ง (จองล่วงหน้าได้)
- เห็น **ผังห้องจริง** ตามที่ครูจัดไว้ — โต๊ะไหนว่าง โต๊ะไหนมีคนจองแล้ว
- แตะโต๊ะที่ว่าง กรอกชื่อ-นามสกุลและชั้น/ห้อง → จองเสร็จ ได้ **รหัสการจอง** เช่น `JT-86TP`
- การจองเป็นแบบ **ทั้งวัน** และ **1 คนจองได้ 1 โต๊ะต่อห้องต่อวัน**
- มีส่วน “การจองของฉัน” ให้ดูและยกเลิกได้

### หน้าครู (`teacher.html`)
- สร้าง / เปลี่ยนชื่อ / ลบห้องเรียน
- **จัดผังห้องด้วยการลากวาง**
  - ลากไอเท็ม (โต๊ะนักเรียน, โต๊ะครู, ประตู, กระดาน) จากแถบเครื่องมือมาวางในตาราง
  - บนมือถือ: แตะไอเท็ม 1 ครั้ง แล้วแตะช่องว่างในตารางเพื่อวาง
  - ลากโต๊ะที่วางแล้วเพื่อย้าย / สลับที่ · ลากออกนอกตารางเพื่อลบ
  - ปรับขนาดตารางได้ (กว้าง 4–16 ช่อง, สูง 3–14 ช่อง)
  - ปุ่มลัด: **ผังมาตรฐาน 40 ที่นั่ง** (8 โต๊ะ × 5 แถว เว้นทางเดินกลาง), เติมโต๊ะให้เต็มผัง, ล้างผัง
  - เลขโต๊ะเรียงอัตโนมัติจากบนลงล่าง ซ้ายไปขวา
- ดู **รายการจองรายวัน** ลบการจองทีละรายการหรือล้างทั้งวัน
- **ดาวน์โหลด CSV** (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน)
- **ส่งออก / นำเข้าไฟล์ข้อมูล** สำหรับย้ายข้อมูลข้ามเครื่อง หรือสำรองกันข้อมูลหาย

## 🚀 วิธีเอาขึ้นเป็นเว็บจริง (GitHub Pages — ฟรี)

1. เปิด repo นี้บน GitHub → แท็บ **Settings**
2. เมนูซ้าย เลือก **Pages**
3. ที่หัวข้อ *Build and deployment* → **Source: Deploy from a branch**
4. เลือก branch (เช่น `main`) และโฟลเดอร์ **`/ (root)`** → กด **Save**
5. รอสักครู่ เว็บจะขึ้นที่

   ```
   https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/joakong/
   ```

   หน้าครูอยู่ที่ `.../joakong/teacher.html`

> อยากให้เว็บอยู่ที่ URL สั้นๆ (ไม่มี `/joakong/`) ให้ย้ายไฟล์ในโฟลเดอร์ `joakong/` ไปไว้ที่ราก repo แทน

### ทางเลือกอื่น
- **เปิดในเครื่องเฉยๆ:** ดับเบิลคลิก `index.html` ได้เลย
- **รันเซิร์ฟเวอร์ทดสอบ:** `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000`
- **Netlify / Vercel:** ลากโฟลเดอร์นี้ไปวางในหน้า deploy ได้ทันที ไม่ต้องตั้งค่า build อะไรเลย

## ⚠️ ข้อจำกัดที่ควรรู้ (สำคัญตอนนำเสนอ)

เว็บนี้ **ไม่มีเซิร์ฟเวอร์** ข้อมูลทุกอย่างเก็บใน `localStorage` ของเบราว์เซอร์ ซึ่งแปลว่า:

| เรื่อง | ผลที่เกิดขึ้น |
|---|---|
| ข้อมูลอยู่แยกกันแต่ละเครื่อง | นักเรียนที่เปิดจากมือถือตัวเอง จะ**ไม่**เห็นการจองของเพื่อน |
| ล้างข้อมูลเบราว์เซอร์ | ข้อมูลหายหมด (จึงควรกด “ส่งออกไฟล์ข้อมูล” เก็บไว้) |
| เปิดโหมดไม่ระบุตัวตน | ข้อมูลหายเมื่อปิดหน้าต่าง |
| หน้าครู | ไม่มีรหัสผ่าน ใครเปิด URL ก็แก้ผังได้ |

**วิธีเดโมให้เวิร์ก:** ใช้เครื่องเดียว (เช่น คอมของครูต่อโปรเจกเตอร์) เป็นเครื่องกลาง
ให้นักเรียนผลัดกันมาจองที่เครื่องนั้น — ทุกคนจะเห็นผังเดียวกันแบบเรียลไทม์

**ถ้าจะทำให้ใช้ได้จริงทั้งโรงเรียน** ต้องเพิ่ม backend + ฐานข้อมูล (เช่น Firebase หรือ Supabase)
แล้วเปลี่ยนเฉพาะไฟล์ `assets/js/store.js` ให้ไปอ่าน/เขียนฐานข้อมูลแทน `localStorage`
— ส่วนหน้าตาและ logic ที่เหลือใช้ต่อได้เลย เพราะแยกชั้นข้อมูลไว้แล้ว

## 📁 โครงสร้างไฟล์

```
joakong/
├── index.html              หน้านักเรียน — เลือกห้อง เลือกวัน จองโต๊ะ
├── teacher.html            หน้าครู — จัดผัง ดูรายการจอง
├── README.md
└── assets/
    ├── css/style.css       สไตล์ทั้งเว็บ (ธีมสีสด ขอบหนา เงาแข็ง)
    └── js/
        ├── store.js        ชั้นข้อมูล + ตัวช่วย UI ที่ใช้ร่วมกันทั้งสองหน้า
        ├── app.js          logic หน้านักเรียน
        └── teacher.js      logic หน้าครู (ตัวแก้ไขผัง + รายการจอง)
```

### รูปแบบข้อมูล

```js
// ห้องเรียน
{ id, name, note, cols, rows, items: [ { id, kind, c, r, label } ], createdAt, updatedAt }
//   kind: 'seat' | 'teacher' | 'door' | 'board'   ·   c, r = พิกัดในตาราง (เริ่มที่ 0)

// การจอง
{ id, code, roomId, roomName, date, seatId, seatLabel, studentName, studentClass, createdAt }
```
